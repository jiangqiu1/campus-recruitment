## 设计要点（论文可引用）

1. **逻辑删除统一**：业务表带 `deleted` 字段，MyBatis-Plus `@TableLogic` 全局过滤
2. **敏感字段加密**：`sys_user.phone`、`company.contact_phone` 采用 AES/CBC + 随机 IV（`v1:` 前缀格式），密码 BCrypt 且 JSON 序列化层 WRITE_ONLY 隔离
3. **状态机约束**：`delivery.status` 五态单向推进由 Service 层强制校验，终态（录用/不合适）锁定
4. **AI 可观测性**：`ai_parse_log` 记录每次调用的 provider/model/latency/mock 标记，是多模型对比实验的数据源
5. **字典约束**：`school_dict` 以唯一名称约束学校字段口径
