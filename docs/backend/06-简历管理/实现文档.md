# 简历管理模块 · 实现文档

> 定位：简历相关类的函数位置。以「类名 + 方法名」为精确定位键。

## 1. 类清单

| 类 | 文件路径 | 职责 |
|----|---------|------|
| ResumeController | `controller/ResumeController.java` | 简历 CRUD、PDF 解析、默认简历 |
| ResumeServiceImpl | `service/impl/ResumeServiceImpl.java` | 简历业务逻辑 |
| Resume | `entity/Resume.java` | 简历实体（表 resume） |

## 3. ResumeServiceImpl — `service/impl/ResumeServiceImpl.java`

业务逻辑较薄，多为 Mapper 透传。核心逻辑在 Controller 层（权限判断、AI 调用联动）。

## 4. Resume 实体 — `entity/Resume.java`

对应表 `resume`。关键字段：`student_id`、`education` / `internship` / `project`（JSON 结构化存储）、`ai_analysis`（AI 分析结果）、`is_default`（默认简历标记）、`complete_score`（完整度）。
