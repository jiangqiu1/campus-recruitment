# 消息通知模块 · 实现文档

> 定位：消息 + 收藏相关类的函数位置。以「类名 + 方法名」为精确定位键。

## 1. 类清单

| 类 | 文件路径 | 职责 |
|----|---------|------|
| MessageController | `controller/MessageController.java` | 学生端消息 |
| UserMessageController | `controller/UserMessageController.java` | 通用消息（管理员/教师/HR） |
| FavoriteController | `controller/FavoriteController.java` | 岗位收藏 |
| Message / UserMessage / Favorite | `entity/` 下对应实体 | 实体 |

## 2. MessageController — `controller/MessageController.java`（学生端）

| 方法 | 行号 | 说明 |
|------|------|------|
| `getMessages` | 25 | 消息列表 |
| `readMessage` | 43 | 标记已读 |
| `getUnreadCount` | 57 | 未读计数 |

对应表 `message`。

## 3. UserMessageController — `controller/UserMessageController.java`（通用端）

| 方法 | 行号 | 说明 |
|------|------|------|
| `getMessages` | 27 | 消息列表 |
| `getUnreadCount` | 36 | 未读计数 |
| `markAsRead` | 48 | 单条已读 |
| `markAllRead` | 58 | 全部已读 |

对应表 `user_message`。

## 4. FavoriteController — `controller/FavoriteController.java`（岗位收藏）

| 方法 | 行号 | 说明 |
|------|------|------|
| `getFavorites` | 30 | 收藏列表 |
| `addFavorite` | 45 | 添加收藏 |
| `removeFavorite` | 75 | 取消收藏 |

对应表 `favorite`。

## 5. Service 与实体

| 类 | 说明 |
|----|------|
| MessageServiceImpl | 学生端消息业务（透传） |
| UserMessageServiceImpl | 通用消息业务（透传） |
| FavoriteServiceImpl | 收藏业务（透传） |
| Message 实体 | 表 message（student_id、content、read_status） |
| UserMessage 实体 | 表 user_message（user_id、content、read_status） |
| Favorite 实体 | 表 favorite（user_id、job_id） |
