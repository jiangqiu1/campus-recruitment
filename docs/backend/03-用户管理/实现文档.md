# 用户管理模块 · 实现文档

> 定位：用户（系统账号）管理相关类的函数位置。以「类名 + 方法名」为精确定位键。

## 1. 类清单

| 类 | 文件路径 | 职责 |
|----|---------|------|
| UserController | `controller/UserController.java` | 管理员对用户的 CRUD |
| CompanyAccountController | `controller/CompanyAccountController.java` | 企业 HR 子账号管理 |
| UserServiceImpl | `service/impl/UserServiceImpl.java` | 用户业务（CRUD 复用 MyBatis-Plus 默认方法） |
| SysUser | `entity/SysUser.java` | 用户实体（表 sys_user） |

## 2. UserController — `controller/UserController.java`（仅管理员）

| 方法 | 行号 | 说明 |
|------|------|------|
| `getAllUsers` | 38 | 用户列表 |
| `getUserById` | 62 | 用户详情 |
| `getUsersByRole` | 83 | 按角色查用户 |
| `createUser` | 109 | 创建用户（BCrypt + AES） |
| `updateUser` | 142 | 更新用户（空密码不覆盖） |
| `deleteUser` | 171 | 删除用户 |
| `updateUserStatus` | 187 | 禁用/启用 |
| `resetPassword` | 210 | 重置密码 |

## 3. CompanyAccountController — `controller/CompanyAccountController.java`

| 说明 | 值 |
|------|-----|
| 路由前缀 | `/companies/{companyId}/accounts` |
| 职责 | 企业 HR 子账号的增删改查 |

## 4. UserServiceImpl — `service/impl/UserServiceImpl.java`

| 方法 | 行号 | 说明 |
|------|------|------|
| `selectByUsername` | 25 | 按用户名查 |
| `selectByWechatOpenid` | 30 | 按微信 openid 查 |
| `login` | 35 | 登录校验 |
| `register` | 63 | 注册 |
| `updatePassword` | 88 | 改密码 |

> 用户的增删改查复用 MyBatis-Plus `IService` 默认方法（save / updateById / removeById / list / page），未单独定义。

## 5. SysUser 实体 — `entity/SysUser.java`

对应表 `sys_user`。关键字段：`username`、`password`（BCrypt 密文）、`phone`（AES 密文）、`role`（0-3）、`status`（启用/禁用）、`company_id`（HR 关联企业）、`school`、`major`、`wechat_openid`。
