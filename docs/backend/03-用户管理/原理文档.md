# 用户管理模块 · 原理文档

> 说明用户账号管理、敏感字段加密、企业子账号的设计意图。

## 1. 设计目标

- 账号统一由管理员创建（系统不开放自由注册，学生注册走 AuthController.register）。
- 敏感字段（手机号）加密存储，展示时解密。
- 密码用 BCrypt，编辑时"空密码"语义为"不修改"。
- 企业 HR 支持主账号 + 子账号。

## 2. 账号创建/更新流程

`UserController.createUser`（109 行）/ `updateUser`（142 行）：

1. 密码用 `BCryptPasswordEncoder.encode` 加密后入库。
2. 手机号用 `AESUtil.encrypt` 加密后入库。
3. **编辑时密码为空则置 null 不覆盖**（避免把空串加密覆盖原密码）。
4. 返回列表时解密手机号，解密失败降级为 `[加密数据]`（保证接口不因解密异常而失败）。

## 3. 敏感字段加密

- 手机号：`AESUtil`（AES/CBC/PKCS5Padding）加密，密钥/IV 来自配置（见认证模块「已知问题」——默认密钥硬编码）。
- 展示链路：列表/详情返回前解密，前端无感。

## 4. 角色与状态

- 角色 `role`：0 学生 / 1 教师 / 2 HR / 3 管理员，创建时指定。
- 状态 `status`：`updateUserStatus`（187 行）切换启用/禁用，禁用用户无法登录（`UserServiceImpl.login` 校验账号状态）。

## 5. 企业 HR 子账号

`CompanyAccountController`（`/companies/{companyId}/accounts`）管理某企业下的 HR 子账号。子账号通过 `company_id` 关联企业，从而继承企业级数据权限（只看本企业岗位/简历）。

## 6. 权限

`UserController` 全部接口仅管理员可调用（`requireAdmin()`）。学生注册走 `AuthController.register`，不经过本模块。
