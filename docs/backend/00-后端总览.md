## 3. 架构分层

```
controller（22）──► service（17）──► service/impl（17）──► mapper（18）──► MySQL
       │                                                     │
       │ 依赖                                                │
       ▼                                                     ▼
config / interceptor / aspect / utils / exception / enums   Redis（缓存、Token）
```

- Controller 只做参数校验、权限判断、调用 Service、组装返回。
- ServiceImpl 承载业务逻辑（状态流转、数据隔离、事务）。
- Mapper 为 MyBatis-Plus BaseMapper，少量自定义 SQL 在 `resources/mapper/*.xml`。

## 7. 关键机制概览

| 机制 | 一句话说明 | 详见 |
|------|-----------|------|
| JWT 认证 | 登录签 token（含 tokenVersion），拦截器 7 步校验，改密码/登出使旧 token 失效 | `01-认证模块/原理文档.md` |
| AI 集成 | RestTemplate 调 DeepSeek，强制 JSON 输出，容错解析，无 Key 时 mock 降级 | `02-AI模块/原理文档.md` |
| 三层权限 | 路由级（JWT 拦截）→ 接口级（requireXxx）→ 数据级（Service 内过滤） | 各模块文档 |
| 安全 | AES 加密敏感字段、BCrypt 密码、MyBatis-Plus 逻辑删除 | 见各模块 |
