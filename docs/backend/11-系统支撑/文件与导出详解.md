# 系统支撑模块 · 文件与导出详解（深度补充）

> 本文档基于 `FileController.java`、`DataExportController.java` 源码，记录文件上传与数据导出的完整实现与已知问题。

## 1. 文件上传（FileController.upload，38 行）

```
① 非空校验 → ② 大小校验（10MB）→ ③ 类型校验（resume=PDF / avatar=JPG/PNG/JPEG）
④ UUID 生成唯一文件名
⑤ 按日期分目录：{type}/{yyyy-MM-dd}/（如 resume/2026-06-03/）
⑥ mkdirs 建目录 → ⑦ transferTo 落盘 → ⑧ 返回 {url, fileName, fileSize}
```

- 配置：`file.upload-path`（本地目录）、`file.access-url`（访问前缀）。
- 删除（`delete`，112 行）：用 `fileUrl.replace(accessUrl, uploadPath)` 反推本地路径删除。

## 2. 数据导出（DataExportController.export，54 行）

**权限**：仅教师（role=1）/ 管理员（role=3），否则 403。

**三种格式**：

| 格式 | 实现 | 特点 |
|------|------|------|
| xlsx | Apache POI `SXSSFWorkbook` | 流式写入，表头蓝底白字、自动列宽（中文按 2 字节） |
| csv | 手动拼接 | 加 UTF-8 BOM（避免 Excel 打开乱码），引号转义 |
| pdf | OpenPDF | A4 横向，隔行灰底，中文字体 |

**五类数据**：student / company / job / delivery / resume，各自表头 + 筛选字段。

**中文字体加载**（`loadChineseFont`，248 行）：依次尝试 `msyh.ttc` → `simhei.ttf` → `simsun.ttc` → `arialuni.ttf`，全部失败 fallback Helvetica（此时中文会乱码）。

## 3. 已知问题（重要）

1. **路径穿越隐患**（已修复 2026-08-31）：`delete` 原通过 URL 反推本地路径、`fileUrl` 客户端可控，现已加 5 层防护——① 前缀白名单（startsWith accessUrl）② 拒绝 `..`/`\` ③ 转本地路径 + `getCanonicalPath` 规范化 ④ 规范化后校验仍在上传目录内 ⑤ 拒绝删除目录。
2. **导出手机号未解密**（已修复 2026-08-31）：`getExportData` 的 student（原 292 行）/ company（原 310 行）原直接输出密文，现改为 `decryptSafely(u.getPhone())` / `decryptSafely(c.getContactPhone())`（现 308 / 326 行），新增私有方法 `decryptSafely`（282 行，解密失败返回原值），注入 `AESUtil`。同时修复了 student 筛选里 `u.getPhone().contains(filter)` 的密文匹配问题（现 305 行），改为 `decryptSafely(u.getPhone()).contains(filter)` 解密后匹配。
3. **导出接口无大小限制**：`getExportData` 用 `list()` 全量加载，数据量大时会内存溢出（应分页/流式）。
