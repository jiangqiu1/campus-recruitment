# 企业管理模块 · 原理文档

> 说明企业入驻、审核、合作等级管理、数据级权限与通知机制。

## 1. 设计目标

- 企业入驻需管理员审核，审核通过后才能发布岗位。
- 合作等级用于区分企业的合作深度（影响排序/推荐）。
- HR 只能操作本企业数据（数据级权限）。

## 2. 企业入驻审核流程

```
企业 HR 提交入驻（createCompany 175）──► 通知所有管理员
                                          │
                                  管理员审核（approveCompany 75 / rejectCompany 96）
                                          │
                        通过 ──► notifyCompanyHr 通知企业 HR（340 行）
                        拒绝 ──► 企业状态置为拒绝
```

- `createCompany`（175 行）创建后通知所有管理员处理。
- 审核通过/拒绝均需 `requireAdmin()`（接口级权限）。
- 审核通过后调 `notifyCompanyHr`（340 行）发消息通知该企业 HR。

## 3. 数据级权限（HR 只看本公司）

`updateCompany`（213 行）：HR 仅能修改 `companyId` 匹配的本企业，其它企业返回无权限。

## 4. 合作等级管理

`updateCooperationLevel`（298 行）由管理员调整企业的合作等级（如普通/重点/战略），影响企业在前端的排序与推荐权重。

## 5. 敏感字段

企业联系电话 `contact_phone` 用 AES 加密存储（同用户手机号）。
