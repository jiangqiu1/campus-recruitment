# 企业管理模块 · 实现文档

> 定位：企业相关类的函数位置。以「类名 + 方法名」为精确定位键。

## 1. 类清单

| 类 | 文件路径 | 职责 |
|----|---------|------|
| CompanyController | `controller/CompanyController.java` | 企业入驻/审核/等级管理 |
| CompanyServiceImpl | `service/impl/CompanyServiceImpl.java` | 企业业务逻辑 |
| Company | `entity/Company.java` | 企业实体（表 company） |

## 2. CompanyController — `controller/CompanyController.java`

| 方法 | 行号 | 说明 |
|------|------|------|
| `getAllCompanies` | 45 | 企业列表 |
| `approveCompany` | 75 | 审核通过（仅管理员） |
| `rejectCompany` | 96 | 审核拒绝（仅管理员） |
| `getCompanyById` | 116 | 企业详情 |
| `getCompaniesByCooperationLevel` | 137 | 按合作等级 |
| `getCompaniesByIndustry` | 157 | 按行业 |
| `createCompany` | 175 | 入驻申请 |
| `updateCompany` | 213 | 更新企业（HR 仅能改本公司） |
| `deleteCompany` | 279 | 删除企业 |
| `updateCooperationLevel` | 298 | 更新合作等级 |
| `searchCompanies` | 320 | 搜索 |
| `notifyCompanyHr`（private） | 340 | 审核后通知 HR |

## 3. CompanyServiceImpl — `service/impl/CompanyServiceImpl.java`

业务逻辑较薄，多为 Mapper 透传。核心逻辑在 Controller 层（权限判断、通知联动）。

## 4. Company 实体 — `entity/Company.java`

对应表 `company`。关键字段：`name`、`industry`、`size`、`city`、`description`、`contact_phone`（AES 密文）、`cooperation_level`（合作等级）、`status`（审核状态）。
