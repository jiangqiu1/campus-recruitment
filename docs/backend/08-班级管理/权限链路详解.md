# 班级模块 · 权限链路详解（深度补充）

> 本文档基于 `ClassController.java` 源码，记录「教师 → 班级 → 学生」这条数据级权限链路的完整实现。这条链路是全项目数据隔离的地基，投递、简历模块都依赖它。

## 1. 权限链全景

```
教师（role=1）
   │
   ▼  selectByTeacherId(teacherId)
班级（class.teacher_id）
   │
   ▼  student_class 关联表
学生（role=0）
   │
   ├──► 简历（resume）    教师只能看本班学生的简历
   └──► 投递（delivery）  教师只能看本班学生的投递
```

班级模块是这条链的**中间枢纽**：教师先定位自己的班级，再由班级定位学生，最后才能访问学生的简历/投递。

## 2. 班级归属校验（checkClassOwnership，381 行）

```java
if (Objects.equals(role, 3)) return;            // 管理员跳过
Class clazz = classService.getById(classId);
if (clazz == null) throw new BusinessException(404, "班级不存在");
if (!Objects.equals(clazz.getTeacherId(), getCurrentUserId()))
    throw new BusinessException(403, "无权操作其他教师的班级");
```

所有涉及班级内操作的方法（加学生/移除学生/查学生/批量操作）都先调用此方法。

## 3. 班级列表的数据级过滤（getAllClasses，60 行）

```java
if (Objects.equals(role, 1)) {
    classes = classService.selectByTeacherId(getCurrentUserId());   // 教师只看自己班
} else {
    classes = classService.list();                                  // 其他角色看全部
}
```

同类的 `getClassesByTeacherId`（162 行）也校验：非管理员只能查自己的班级（`!role==3 && teacherId != 当前用户` → 403）。

## 4. 班级统计（fillClassStatistics，77 行）

一次批量查询避免 N+1：

1. 收集所有班级的学生 id（`getStudentIdsByClassId`）。
2. 用 `in(allStudentIds)` **一次性**查所有学生的投递记录。
3. 按班级遍历，计算：
   - 学生数 = 班级学生 id 数
   - 投递数 = 本班学生投递总数
   - **就业率** = 有录用记录（delivery.status=3）的学生数 / 学生数 × 100

## 5. 学生档案组装（getClassStudents，287 行）

教师查看本班学生时，每个学生组装：

| 字段 | 计算方式 |
|------|---------|
| 简历完整度 resumeComplete | education 有值 +40，skills 有值 +30，selfEvaluation 有值 +30 |
| AI 评分 aiScore | 从 `resume.aiAnalysis` JSON 解析 `overallScore` |
| 投递数 deliveryCount | `deliveryService.countByStudentId` |
| 手机号 | AES 解密展示 |

## 6. 跨模块的权限链体现

| 模块 | 如何依赖班级链路 |
|------|----------------|
| 投递 `getAllDeliveries` | 先查本班学生 id 列表，再过滤投递 |
| 简历 `getStudentResume` | 校验学生是否在本班（教师才能看） |
| 班级 `getClassStudents` | checkClassOwnership + 按班级查学生 |

## 7. 权限链的关键设计点

1. **单一枢纽**：教师权限始终收敛到 `class.teacher_id` 这一个字段，避免散落各处的角色判断。
2. **批量查询**：`fillClassStatistics` 和投递模块的 `enrichDeliveries` 都用 `in(...)` 批量查询，消除 N+1。
3. **管理员旁路**：`checkClassOwnership` 对管理员直接放行，管理员可看/操作任何班级。
