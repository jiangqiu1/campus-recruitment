# 班级管理模块 · 原理文档

> 说明班级归属、数据级权限、班级统计与学生档案组装。

## 1. 设计目标

- 班级归属教师，教师只能管理自己的班级（数据级权限）。
- 班级是「教师 → 学生」权限链的核心中间层。
- 班级列表需附带统计（学生数、就业率、投递数）。

## 2. 数据级权限（教师 → 班级）

`getAllClasses`（60 行）：教师只返回 `selectByTeacherId(currentUserId)` 的班级；`checkClassOwnership`（381 行）在操作班级前校验归属。

## 3. 班级统计

`fillClassStatistics`（77 行）为每个班级计算：

- 学生数：关联表 student_class 计数。
- 投递数：本班学生的投递总数。
- **就业率**：录用（delivery.status=3）学生数 / 总学生数。

## 4. 学生入班/出班

- `addStudentToClass`（252 行）单学生入班；`batchAddStudentsToClass`（343 行）批量入班。
- `removeStudentFromClass`（272 行）单学生出班；`batchRemoveStudentsFromClass`（363 行）批量出班。

## 5. 学生档案组装（getClassStudents，287 行）

返回本班学生列表，附带：

- 简历完整度：教育 40 + 技能 30 + 自评 30（三部分加权）。
- AI 评分：从简历评分记录取。
- 投递数：该学生的投递记录数。

这构成教师查看全班就业进度的数据基础（投递看板的数据源）。

## 6. 权限链定位

班级模块是三层权限中「数据级」的关键一环，链路为：

```
教师 ──► 班级（teacher_id）──► 学生（student_class）──► 简历/投递
```

投递模块、简历模块的数据隔离都依赖这条链路（先查本班学生 id，再过滤业务数据）。
