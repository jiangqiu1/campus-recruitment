# 布局与组件

> 定位：`layouts/`（3 个布局）+ `components/`（3 个组件）。

## 1. 三个布局（layouts/）

三者结构高度一致：`aside 侧边栏（el-menu router 模式）+ wrapper（navbar 顶部栏 + main 容器 router-view + footer 页脚）`。

顶部栏均为：折叠按钮 + Breadcrumb + NotificationBell + 用户下拉（个人信息/修改密码/退出登录）。

| 布局 | 侧边栏菜单 |
|------|-----------|
| AdminLayout | 数据大屏、用户管理、企业管理、岗位监管、企业审核、班级管理、AI使用统计、操作日志、数据导出、系统设置 |
| TeacherLayout | 工作台、班级管理、简历管理、AI岗位发布、投递看板、AI人岗匹配、AI简历分析、企业详情、审批管理 |
| HRLayout | 简历处理、候选人管理、面试管理、岗位管理、岗位分析、数据统计、企业信息、账号管理 |

**已知问题**：
- 三个布局的折叠状态用**各自本地 `ref(isCollapse)`**，未用 app.js 的 `sidebarCollapsed`。
- 三个布局模板/样式/折叠逻辑/用户下拉几乎完全复制，仅菜单项不同，可抽公共 `BaseLayout`。

## 2. 三个组件（components/）

| 组件 | props | 职责 |
|------|-------|------|
| Breadcrumb | 无（内部 useRoute） | 根据 `route.matched` 中带 `meta.title` 的记录生成面包屑 |
| NotificationBell | 无 | 消息铃铛：调 userMessageAPI 拉未读/列表，5 秒轮询，支持已读/全部已读，viewAll 按 userRole 跳转 |
| ResumeDetailDialog | visible/studentId/className/mode/hrScore 等 | 简历详情弹窗（左简历内容 + 右 AI 评分），mode=teacher 显评分，mode=hr 显匹配度 |

## 3. 已知问题

1. **布局重复代码**：三布局可抽 BaseLayout（见上）。
2. **消息菜单缺失**：TeacherLayout / HRLayout 侧边栏无「消息」入口，只能靠铃铛进入，且 messages 路由复用 admin 的 MessageList.vue。
3. **ResumeDetailDialog 死代码**：`hasResumeData` computed 定义但模板未使用。
