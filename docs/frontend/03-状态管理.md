## 1. user.js — 用户状态（核心，使用中）

**state**：`token`、`userInfo`、`roles`、`permissions`（均从 localStorage 初始化）。

**computed**：`userRole`（21 行，把后端数字 role 映射成字符串）、`isAdmin/isTeacher/isHR/isStudent`。

**角色映射**（21-24 行）：
```js
const roleMap = { 0: 'student', 1: 'teacher', 2: 'hr', 3: 'admin' }
const userRole = computed(() => roleMap[rawRole.value] || '')
```

**action**：`login`、`logout`（设置 `window.__isLoggingOut` 防抖）、`getUserInfo`、`updateUserInfo`、`changePassword`、`hasPermission`、`hasRole`。

> 注：`checkToken` action 已删除（2026-09-07，P2-9）——它调用不存在的 `GET /auth/check` 且无任何页面引用，属死代码链。

**引用点**：三个布局（Admin/Teacher/HRLayout）、Profile、Password、多个业务页面（AIMatch、ClassManagement、BatchResume、JobAnalysis 等）均通过 `useUserStore()` 读取 `companyId` 等。

## 2. 已删除的 store（历史说明）

- **app.js**：主题/侧边栏/面包屑/标签页缓存等全局 UI 状态，无任何页面引用。
- **job.js / resume.js**：岗位/简历状态，无页面引用，且成功分支存在 `response.data.data` 的 `ReferenceError`（变量名应为 `res`）。因从未接线，bug 一直未触发。

## 3. 已知问题

1. **登录状态两套写入**（已修复，见 P1-8）：`Login.vue` 原存 roleName 字符串，与 store 期待的数字 role 不一致；已统一为数字 role。
2. **主题/侧边栏等 UI 状态管理缺失**：删除 app.js 后，全局 UI 状态（主题切换、侧边栏折叠）目前无人管理。若后续需要主题切换等功能，需重新设计（建议在布局组件内实现或新建精简 store）。
