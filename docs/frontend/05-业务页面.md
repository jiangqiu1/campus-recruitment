# 业务页面

> 定位：`views/` 下 30 个 PC 页面。记录每个页面的职责与 API 依赖。
> （2026-09-30 已删除原 `views/miniprogram/` 下 11 个未挂载页面，git 历史可查；学生端小程序在独立工程 job-miniprogram）

## 1. 管理员端（admin，11 个）

| 页面 | 职责 | 主要 API |
|------|------|---------|
| Dashboard.vue | 数据大屏（总览/趋势/热门岗位/最近动态） | statisticsAPI |
| UserManage.vue | 用户 CRUD + 批量删除 + 启用禁用 | userAPI |
| CompanyManage.vue | 企业 CRUD | companyAPI |
| JobOversight.vue | 全局岗位监管（上下架/删除） | jobAPI + companyAPI + userAPI |
| EnterpriseAudit.vue | 企业入驻审核 + 岗位变更审批 | companyAPI + jobChangeAPI |
| ClassManage.vue | 班级 CRUD + 学生关联（批量加/移除） | classAPI + userAPI |
| AIStats.vue | AI 使用统计（解析/匹配/评分日志） | aiParseAPI + jobMatchAPI + resumeScoreAPI |
| OperationLog.vue | 操作日志查看/删除 | operationLogAPI |
| DataExport.vue | 数据导出（blob 下载） | dataExportAPI |
| SystemSettings.vue | 系统设置（基础/安全/通知） | settingsAPI |
| MessageList.vue | 消息列表 | userMessageAPI |

## 2. 教师端（teacher，9 个）

| 页面 | 职责 | 主要 API |
|------|------|---------|
| Dashboard.vue | 工作台（仪表盘 + 趋势 + 就业分布） | statisticsAPI |
| ClassManagement.vue | 班级管理（按教师查班级 + 学生关联） | classAPI + userAPI |
| ResumeManage.vue | 简历管理（按班级筛学生） | classAPI + resumeAPI |
| JobPosting.vue | AI 岗位发布（CRUD + AI 解析岗位文本） | jobAPI + companyAPI + aiParseAPI |
| DeliveryBoard.vue | 投递看板 | jobAPI + deliveryAPI + resumeAPI |
| AIMatch.vue | AI 人岗匹配（单条/批量生成/推送） | jobAPI + classAPI + jobMatchAPI |
| AIParse.vue | AI 简历分析 | classAPI + aiParseAPI |
| CompanyDetail.vue | 企业详情列表 | companyAPI |
| Approvals.vue | 审批管理（岗位变更审批） | jobChangeAPI |

## 3. HR 端（hr，8 个）

| 页面 | 职责 | 主要 API |
|------|------|---------|
| BatchResume.vue | 简历处理（投递 + 单条/批量评分 + 状态流转） | deliveryAPI + resumeScoreAPI + jobAPI |
| CandidateManage.vue | 候选人管理（投递/评分/面试/录用） | jobAPI + deliveryAPI + resumeScoreAPI |
| InterviewManage.vue | 面试管理（安排 + 状态更新） | deliveryAPI + jobAPI |
| JobManage.vue | 岗位管理（发布/暂停/关闭/删除） | jobAPI |
| JobAnalysis.vue | 岗位分析（平均分/匹配分布/维度分） | jobAPI + resumeScoreAPI |
| DataStats.vue | 数据统计（HR 仪表盘 + 趋势） | statisticsAPI + jobAPI + deliveryAPI |
| CompanyProfile.vue | 企业信息查看/编辑 + HR 仪表盘 | companyAPI + statisticsAPI |
| AccountManagement.vue | 企业子账号 CRUD | companyAccountAPI |

## 4. 通用页面（根目录，3 角色共用）

| 页面 | 职责 | API |
|------|------|-----|
| Profile.vue | 个人信息查看/编辑（含头像） | authAPI + useUserStore |
| Password.vue | 修改密码 | useUserStore.changePassword |
