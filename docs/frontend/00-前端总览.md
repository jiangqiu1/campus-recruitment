# 前端总览

> 校园招聘就业管理平台 · 前端（Vue 3 PC 管理后台）
> 本文档为前端「文档基线」，代码改动需同步更新本文档与对应模块文档。

## 1. 项目概览

| 项 | 值 |
|---|---|
| 框架 | Vue 3（Composition API）+ Vite |
| UI 库 | Element Plus 2.4（全量引入 + 图标全量注册） |
| 状态管理 | Pinia 2.1 |
| 路由 | Vue Router 4（createWebHistory） |
| 请求 | Axios（baseURL `/api`，timeout 15s） |
| 图表 | ECharts 5 |
| 源码规模 | `src/` 共 60 文件（49 .vue + 8 .js + 2 svg + 1 css） |
| 运行端口 | 5173（dev） |

## 2. 三层架构

```
视图层 views/（30 PC 页面；2026-09-30 已删除未挂载的 11 个 miniprogram 页面）
   │
   ├──► 路由层 router/（三端布局路由 + 权限守卫）
   ├──► 状态层 stores/（Pinia：user）
   └──► 请求层 api/（axios 封装 + 17 个 API 模块）
              │
              ▼  HTTP /api（JWT Bearer）
         Spring Boot 后端
```

## 3. 目录结构

| 目录/文件 | 说明 |
|-----------|------|
| main.js | 入口（注册 ElementPlus、图标、Pinia、Router） |
| App.vue | 根组件 |
| api/index.js | axios 实例 + 17 个 API 模块封装 |
| router/index.js | 三端路由表 + 全局权限守卫 |
| stores/ | Pinia：user.js（app/job/resume 已删除） |
| layouts/ | AdminLayout / TeacherLayout / HRLayout |
| components/ | Breadcrumb / NotificationBell / ResumeDetailDialog |
| utils/formatDate.js | 日期格式化 |
| utils/score.js | 评分契约统一工具（刻度归一、维度解析、颜色阈值） |
| styles/main.css | 全局样式 |
| views/pc/ | PC 页面：admin 11 + hr 8 + teacher 9 + 通用 2 |
| ~~views/miniprogram/~~ | 已删除（2026-09-30，11 个未挂载页面，git 历史可查） |
