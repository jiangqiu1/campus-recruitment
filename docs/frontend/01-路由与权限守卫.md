# 路由与权限守卫

> 定位：`router/index.js`（357 行）。记录三端路由表结构与全局权限守卫逻辑。

## 1. 路由表结构

三端各自一个父路由（layout 作为 component），子路由为具体页面：

```
/login                     Login（独立，无布局）
/admin        AdminLayout  ─► dashboard/users/companies/jobs/audit/classes/
                              ai-stats/logs/export/settings/profile/password/messages
/teacher      TeacherLayout─► dashboard/classes/resumes/jobs/deliveries/ai-match/
                              ai-parse/companies/approvals/profile/password/messages
/hr           HRLayout     ─► resumes/stats/analysis/accounts/jobs/candidates/
                              interviews/company/profile/password/messages
/             redirect /login
/:pathMatch(.*)*  redirect /login   （404 兜底）
```

**路由 meta**：每个子路由 `meta: { title, role }`，role 取值 `admin`/`teacher`/`hr`。

**懒加载**：仅 MessageList 用 `() => import(...)`（135 行）动态导入，其余页面顶部静态 import。

## 2. 全局路由守卫（beforeEach，317 行）

```js
router.beforeEach((to, from, next) => {
  const token = localStorage.getItem('token')
  const userRole = localStorage.getItem('userRole')

  if (to.meta.title) document.title = to.meta.title + ' - 招聘就业管理平台'

  if (to.path === '/login') {
    // 已登录则按角色跳转对应后台
    if (token) { /* admin→/admin/dashboard, teacher→/teacher/dashboard, hr→/hr/resumes */ }
    else next()
  } else {
    if (!token) next('/login')                        // 未登录 → 登录页
    else if (to.meta.role && to.meta.role !== userRole) {
      ElMessage.error('无权访问该页面'); next(false)   // 角色不匹配 → 拦截
    } else next()
  }
})
```

**权限判断流程**：

```
未登录（无 token）──► 跳 /login
已登录访问登录页 ──► 按 userRole 跳转对应后台
已登录访问业务页 ──► 校验 meta.role 是否等于 userRole，不等则拦截
```

## 3. 权限控制的双层结构

| 层 | 位置 | 作用 | 是否安全 |
|----|------|------|---------|
| 前端路由守卫 | router/index.js | UI 层拦截，防止用户看到无权限页面 | 否（可被绕过） |
| 后端接口鉴权 | JwtInterceptor + requireXxx | 真正的安全边界 | 是 |

## 4. 关键实现细节

- **角色来源**：`localStorage.getItem('userRole')`，值为 `admin`/`teacher`/`hr`/`student` 字符串，由 `Login.vue` 登录成功后写入（`STORAGE_KEYS.USER_ROLE`）。
- **token 来源**：`localStorage.getItem('token')`（纯 token，无 Bearer 前缀，登录时已剥离）。
- **页面标题**：`document.title = meta.title + ' - 招聘就业管理平台'`。

## 5. 已知问题

1. **消息路由复用**：`NotificationBell.viewAll` 跳 `/{role}/messages`，但 teacher/hr 的 messages 路由复用 `admin/MessageList.vue`（217、292 行），且 TeacherLayout/HRLayout 侧边栏没有消息菜单入口，只能靠铃铛进入。
2. **前端守卫非安全边界**：`userRole` 存 localStorage 可被用户篡改，前端守卫只做 UI 层体验，真正的权限校验依赖后端。
