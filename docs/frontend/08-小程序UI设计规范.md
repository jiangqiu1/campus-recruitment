# 小程序 UI 设计规范 — 蓝色科技风精修

> 2026-09-30 定稿 · 适用 job-miniprogram 全部页面
> 定位：**精修，不是重画**。保持现有蓝色科技风基调，做三件事：接入 token、收敛冲突色值、统一组件细节。

## 二、色彩规范（含收敛映射）

### 2.1 语义色板（全部映射到 uni.scss 现有变量）

| 语义 | 变量 | 定版值 | 收敛来源 |
|------|------|--------|----------|
| 品牌主色 | `$uni-color-primary` | `#165DFF` | 223 处，定版 |
| 主色渐变 | `$uni-gradient-primary`（**新增**） | `linear-gradient(135deg, #165DFF 0%, #2563EB 100%)` | 首页头部等 23 处 `#2563EB` 仅作渐变终点 |
| **AI 功能色** | `$uni-color-ai`（**定版青色**） | `#0EA5E9`（图标/底色）· `#0284C7`（小字，**新增** `$uni-color-ai-strong`） | 蓝=操作、青=智能，同属冷色光谱；**刻意不用紫色，避开 AI 产品紫渐变俗套**（见 2.3） |
| 成功/录用 | `$uni-color-success` | `#00B42A` | 33 处 |
| 警示 | `$uni-color-warning` | `#FF7D00` | 吸收 `#F59E0B`（见下） |
| 危险/拒绝 | `$uni-color-error` | `#F53F3F` | **吸收 `#EF4444`（30 处）** |
| 一~四级文字 | `$uni-text-color-*` | `#1D2129 / #4E5969 / #86909C / #C9CDD4` | 定版 |
| 页面底 / 卡片 | `$uni-bg-color-page` / `$uni-bg-color` | `#F7F8FA` / `#FFFFFF` | 定版 |
| 分割线 / 边框 | `$uni-border-color-divider` / `$uni-border-color` | `#F2F3F5` / `#E5E6EB` | `#E8EAED` 并入 `#E5E6EB` |

### 2.2 业务状态色（与 UI 语义色对齐）

投递/岗位状态色集中在 `utils/request.js` 的 `DELIVERY_STATUS` / `JOB_STATUS` 常量，随本规范对齐：

| 状态 | 现值 | 定版 |
|------|------|------|
| 待查看 / 草稿 | `#F59E0B` | `#FF7D00`（warning） |
| 已查看 / 面试中 / 招聘中 | `#165DFF` | 不变（primary） |
| 已录用 | `#8B5CF6` | 不变（低频业务状态色，保留） |
| 不合适 / 已关闭 | `#EF4444` / `#86909C` | `#F53F3F` / 不变 |

### 2.3 AI 功能视觉语言（本次精修的重点差异化）

> 决策记录：紫渐变 + 闪光图标是当下 AI 产品的通用俗套，本产品定位求职工具、要"克制可信"，
> 故 **AI 色不用紫色**，改用青色系，与主蓝同属冷色光谱：**蓝 = 操作，青 = 智能**。

- **AI 色**：图标/强调/浅底用 `#0EA5E9`（浅底 `rgba(14, 165, 233, 0.1)`）；小字号文字用深一档 `#0284C7` 保证可读性；
- **AI 入口**：青色图标（✨/魔法棒/对话气泡，统一图标语言）+ 青色文字（如简历页「AI 诊断」、首页「模拟面试」）；
- **AI 结果卡**：白底 + 青色徽标（类型标签 `技术/项目/行为` 等）+ 分数用状态色；
- **AI 生成中**：骨架屏 + 「AI 正在…」文案 + 青色 shimmer 微光动效（interview-practice 现有模式升级）；
- uni.scss 原有的 `$uni-color-ai: #0EA5E9` 定版保留，增补 `$uni-color-ai-strong: #0284C7`；
- 已录用的状态紫 `#8B5CF6` 为低频业务状态色（非 AI 语义），保留不动。

## 三、字号 / 圆角 / 间距 / 阴影收敛

### 3.1 字号（10 档 → 8 档）

定版：`12 / 13 / 14 / 15 / 16 / 18 / 20 / 24`（uni.scss 增补 13/15 两档，20/24 并入现有 h 档）

| 现状 | 收敛到 | 用途 |
|------|--------|------|
| 11px | **12px** | 小标签 |
| 12px | 12px（`$uni-font-size-xs`→改 12） | 辅助说明 |
| 13px | 13px（**新增** `$uni-font-size-caption`） | 次要正文 |
| 14px | 14px（`$uni-font-size-base`） | 正文 |
| 15px | 15px（**新增** `$uni-font-size-em`） | 强调正文/按钮 |
| 16px | 16px（`$uni-font-size-h3`） | 卡片标题 |
| 18px | 18px（`$uni-font-size-h2`） | 页面区块标题 |
| 20/22px | 20px（`$uni-font-size-h1` 改 20；22 仅评分大数字特例保留） | 页面大标题 |

### 3.2 圆角（10 档 → 4 档 + 胶囊）

| 现状 | 收敛到 | 变量 |
|------|--------|------|
| 2/3/4px | **4px** | `$uni-border-radius-sm`（标签、输入框内元素） |
| 6/8px | **8px** | `$uni-border-radius-base`（常规按钮、内嵌卡片） |
| 10/12px | **12px** | `$uni-border-radius-lg`（卡片、按钮） |
| 16/20/24px | **16px** / 胶囊 | `$uni-border-radius-xl` / `999px`（搜索框、筛选项） |

### 3.3 阴影（跟随高频现实）

卡片现状高频 `0 2px 8px rgba(0,0,0,0.04)`，**修订 `$uni-shadow-sm` 为该值**（规范跟随现实，改 1 行省几百处）；弹层/悬浮用 base/lg 不变。

### 3.4 间距

沿用规范五档（4/8/12/16/24），页面左右边距统一 16px（现状已基本一致，仅个别 12/20px 页面修正）。

## 四、组件细节规范

| 组件 | 规范 |
|------|------|
| 卡片 | 白底 · 12px 圆角 · `$uni-shadow-sm` · 内边距 16px（信息密集区 20px） |
| 按钮 | 主：primary 实底 12px 圆角 15px 字重 600 · 次：白底 1px `#E5E6EB` 边 · 危险：文字红 · **统一 active 反馈 `opacity: 0.85`** |
| 标签/胶囊 | 4px 小标签 / 999px 胶囊，浅底色 + 同色系文字（现状模式，统一取值） |
| 评分环 | 沿用 ScoreCircle；分数阈值统一 ≥80 绿 / ≥60 蓝 / ≥40 橙 / 其余红 |
| 空态/加载 | 统一 EmptyState / LoadingState 组件，禁止页面自绘 |
| 弹层 | 统一 PopupDrawer（title + maskClosable），禁用自写 fixed 弹层 |
| 状态栏/导航 | custom 页统一 NavBar 组件；状态栏高度动态获取（现状已做，保持） |
| 点按过渡 | 全局 `view/button:active` 0.2s 过渡；列表卡片 `transform: scale(0.98)` |

## 五、改造批次与验收

| 批次 | 范围 | 内容 | 验收标准 |
|------|------|------|----------|
| **0 基建** | uni.scss / App.vue | 按 2.1/3.1 修订 token（AI 色定版、渐变、字号增补、阴影修订）；App.vue 全局 active 过渡 | 编译通过，现有页面视觉无回归 |
| **1 学生端高频** | home、job-detail、resume、deliveries、interview-practice | 替换 token + 组件细节 + AI 紫统一切换 | 该 5 页 grep 硬编码色 ≈0（阴影 rgba 除外）；模拟器过核心路径 |
| **2 学生端其余** | 其余 12 页 | 同上 | 同上 |
| **3 教师端** | 14 页 | 同上 | 同上 |
| **4 HR 端 + common** | 11 + 4 页 | 同上 | 同上 |

**每页改造 checklist**：
1. 颜色字面量 → uni.scss 变量（按第二节映射表，含双红双琥珀合并）；
2. 圆角/字号 → 收敛档位；
3. 卡片/按钮/标签对齐第四节组件规范；
4. AI 相关元素切换 AI 青色体系（含图标语言）；
5. 模拟器走一遍该页核心路径，确认无布局回归。

## 六、工作量与方式

- 批次 0：半小时级，改完全局即可见基础统一（阴影/遮罩/过渡）。
- 批次 1：一次会话可完成；批次 2~4 每批一次会话，按 checklist 机械推进。
- 每批完成后单独 commit，随时可中断，样式收敛后无"半成品感"（token 替换本身不改布局）。
